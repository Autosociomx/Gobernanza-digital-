✅ Nota: Solo tienes que agregar cache_control: { type: "ephemeral" } a tu system prompt. El contenido comprimido hará el 90% del trabajo.

⚠️ Notas específicas para Claude Fable 5

  • Thinking siempre activo — No envíes thinking: {type: "disabled"}, regresa error 400. Simplemente omite el parámetro thinking.
  • Verificar stop_reason — Fable 5 puede responder con "refusal". Siempre revisa stop_reason antes de leer content.
  • Retención de datos — Fable 5 requiere política de 30 días de retención. Sin eso, el API devuelve error 400.
  • Mínimo 2,048 tokens para cachear — El output comprimido (~400 tokens) no alcanza el umbral solo. Combínalo con instrucciones del sistema para superar 2,048 tokens y activar el caché.
  • Precio — Input: $10/MTok | Cache write: $12.50/MTok | Cache read: $1/MTok | Output: $50/MTok

# Nayarit Digital — Landing Page

Landing page institucional migrada desde el repo `nayarit-digital`.

**Stack:** Next.js 14 + Tailwind CSS + TypeScript + Framer Motion  
**Build:** `npm run build` → sitio estático en `out/`  
**Deploy:** Netlify / Vercel / Cloudflare Pages

## Propósito

Vitrina de venta para municipios. Presenta los 6 módulos de cobertura legal
(~90% LNETB) con diseño profesional. No es la app funcional — es la carta de
presentación.

## Relación con SOATM

Esta landing es el frontend de marketing del ecosistema. La app real
(Gobernanza-digital-) es donde corre Aura, el triaje, el gemelo digital, etc.

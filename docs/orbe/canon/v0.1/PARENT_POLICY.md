# Parent policy

`v0.1` no tiene parent porque inicia esta serie documental.

Toda versión posterior de `docs/orbe/canon/` debe declarar en su manifiesto:

- versión parent;
- hash SHA-256 del manifiesto parent o identificador de integridad equivalente;
- HEAD contra el que fue auditada;
- alcance de los cambios respecto al parent.

No se reescribe `v0.1` para reflejar cambios posteriores.

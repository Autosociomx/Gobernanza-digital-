# ORBE P0 v0.2 — alcance congelado

Esta etapa autoriza exclusivamente P0.1, P0.2 y P0.3.

## Incluido

- P0.1: runtime LAB accesible, configuración explícita, CORS allowlist, rate limit básico, honestidad institucional y documentación de despliegue.
- P0.2: suite reproducible de ocho casos para el vertical slice bache/luminaria.
- P0.3: separación visible y documental Aura vs ORBE.

## Excluido

- proveedores de IA adicionales;
- Aura como autorizador;
- `SANDBOX` o `INSTITUTIONAL`;
- segundo contrato semántico;
- intents añadidos como `if` en frontend;
- cambios a Evidence OS;
- borrado de documentación histórica;
- sustitución del registro semántico nativo por inferencia de modelo.

Cualquier cambio fuera de esta lista requiere una etapa posterior y no se considera parte de P0 v0.2.

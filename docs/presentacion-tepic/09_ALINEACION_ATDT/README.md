# 09 — ALINEACIÓN CON EL MODELO NACIONAL (ATDT)

## Ficha estándar

| Campo | Respuesta |
|---|---|
| **Problema** | La LNETB y los Lineamientos del Modelo Nacional establecen requisitos específicos. Es necesario demostrar cómo la propuesta se alinea con ellos, sin pretender certificación |
| **Afectados** | Mejora Regulatoria, ATDT, autoridades de los tres órdenes de gobierno |
| **Obligación/Necesidad** | Alinear la propuesta con el Modelo Nacional de Simplificación y Digitalización (DOF 22-oct-2025) |
| **Propuesta** | Matriz de alineación: cada requisito del Modelo Nacional → cómo se aborda en la propuesta → estado actual |
| **Evidencia** | Documentación del Modelo Nacional referenciada, arquitectura documentada |
| **Brecha** | No tenemos acceso directo a la ATDT. Las referencias son a documentos públicos. La certificación solo puede emitirla la autoridad |
| **Responsable** | Proponente (alineación documentada) + ATDT/Ayuntamiento (validación oficial) |
| **Fundamento** | Lineamientos del Modelo Nacional (DOF 22-oct-2025) |
| **Estado** | 🟡 Preparado — alineación documentada, validación oficial pendiente |
| **Evidencia física** | `09_ALINEACION_ATDT/MATRIZ_DE_ALINEACION.md` |

⚠️ **IMPORTANTE:** Esta carpeta documenta **alineación**, no **cumplimiento** ni **certificación**. La palabra clave es "alineación". La certificación solo puede emitirla la autoridad competente.

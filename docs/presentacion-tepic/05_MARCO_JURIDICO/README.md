# 05 — MARCO JURÍDICO

## Regla maestra de esta carpeta

> Ningún documento puede afirmar que una obligación está cumplida solamente porque existe una funcionalidad tecnológica. Debe existir una cadena de evidencia que conecte: norma → autoridad competente → requisito → implementación → evidencia → estado → autorización pendiente.

Ningún artículo puede aparecer en el expediente institucional si no puede rastrearse hasta una fuente normativa primaria almacenada o enlazada de manera verificable.

## Ficha estándar obligatoria

Cada documento de esta carpeta responde:

| Campo | Pregunta |
|---|---|
| **Problema** | ¿Qué problema público estamos resolviendo? |
| **Afectados** | ¿A quién afecta? |
| **Obligación/Necesidad** | ¿Qué obligación institucional o necesidad pública existe? |
| **Propuesta** | ¿Qué estamos proponiendo? |
| **Evidencia** | ¿Qué podemos demostrar hoy? |
| **Brecha** | ¿Qué todavía NO existe? |
| **Responsable** | ¿Quién debe validar, autorizar o producir lo pendiente? |
| **Fundamento** | ¿Qué norma, artículo o documento oficial sustenta la afirmación? |
| **Estado** | Operativo / Demo / Preparado / Hoja de ruta / No verificado |
| **Evidencia física** | ¿Qué archivo, captura, código, PDF o fuente demuestra el estado? |

## Semáforo de evidencia

| 🟢 VERIFICADO | 🟡 PREPARADO / DEMOSTRABLE | 🔵 POR VERIFICAR | 🟠 REQUIERE AUTORIZACIÓN | 🔴 NO EXISTE |
|---|---|---|---|---|
| Existe evidencia primaria o técnica comprobable | Existe diseño, documentación o prototipo | Requiere confirmación con fuente oficial o autoridad | Depende de autorización institucional | No implementado actualmente |

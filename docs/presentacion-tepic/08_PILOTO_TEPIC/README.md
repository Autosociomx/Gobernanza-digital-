# 08 — PILOTO TEPIC

## Ficha estándar

| Campo | Respuesta |
|---|---|
| **Problema** | Sin un plan de piloto estructurado, no hay ruta clara para pasar del prototipo de laboratorio a una prueba institucional autorizada |
| **Afectados** | Todas las áreas del Ayuntamiento involucradas en la autorización y operación |
| **Obligación/Necesidad** | Demostrar que existe una metodología de implementación progresiva con puntos de control |
| **Propuesta** | Piloto en 6 etapas (A→F): laboratorio → usuarios → institucional → producción limitada → evaluación → escalamiento |
| **Evidencia** | Plan de piloto documentado con criterios GO/NO-GO por etapa |
| **Brecha** | La Etapa C (autorización institucional) depende enteramente del Ayuntamiento |
| **Responsable** | Ayuntamiento (autorización) + proponente (ejecución técnica) |
| **Fundamento** | Metodología de implementación progresiva documentada |
| **Estado** | 🟡 Preparado — Etapa A completada, B–F pendientes de autorización |
| **Evidencia física** | `08_PILOTO_TEPIC/FASES_DE_IMPLEMENTACION.md`, `demo/constancia-residencia/index.html` |

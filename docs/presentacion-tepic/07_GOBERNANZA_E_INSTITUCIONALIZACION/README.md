# 07 — GOBERNANZA E INSTITUCIONALIZACIÓN

## Ficha estándar

| Campo | Respuesta |
|---|---|
| **Problema** | Sin claridad de roles, cualquier proyecto tecnológico ante un Ayuntamiento genera confusión sobre quién decide, quién autoriza y quién opera |
| **Afectados** | Presidencia, Secretaría, Jurídico, dependencias municipales |
| **Obligación/Necesidad** | El Ayuntamiento conserva todas sus facultades de decisión, autorización y validación. El proponente solo propone y construye |
| **Propuesta** | Separar explícitamente: qué es del Ayuntamiento y qué es del proponente tecnológico |
| **Evidencia** | Roles documentados en el expediente regulatorio y este README |
| **Brecha** | Sin designación formal de enlace institucional ni funcionario firmante |
| **Responsable** | Ayuntamiento (designaciones) + proponente (propuesta de gobernanza) |
| **Fundamento** | CPEUM Art. 115; Ley Orgánica Municipal de Nayarit |
| **Estado** | 🟡 Preparado — modelo de gobernanza diseñado, designaciones pendientes |
| **Evidencia física** | Este documento y `07_GOBERNANZA/MODELO_DE_GOBERNANZA.md` |

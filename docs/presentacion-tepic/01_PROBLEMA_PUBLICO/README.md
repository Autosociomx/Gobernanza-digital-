# 01 — PROBLEMA PÚBLICO

## Ficha estándar

| Campo | Respuesta |
|---|---|
| **Problema** | Los ciudadanos de Tepic deben realizar múltiples visitas presenciales y presentar documentos físicos para trámites municipales simples — documentos que otras dependencias del propio municipio ya poseen |
| **Afectados** | Residentes del municipio de Tepic (~490,000 habitantes) que requieren constancias, permisos y certificaciones municipales |
| **Obligación/Necesidad** | LNETB (DOF 16-jul-2025) obliga a los tres órdenes de gobierno a simplificar, digitalizar y eliminar trámites. Ley de Gobierno Digital de Nayarit (Arts. 2, 5, 6) obliga a los municipios a implementar gobierno digital |
| **Propuesta** | Laboratorio piloto con un solo trámite (Constancia de Residencia) para demostrar el modelo de simplificación |
| **Evidencia** | Prototipo funcional en `demo/constancia-residencia/index.html`. Documentación de proceso AS-IS en `03_REINGENIERIA/` |
| **Brecha** | Los datos reales del trámite (volumen mensual, tiempos reales, costos) deben ser proporcionados por el Ayuntamiento. Sin línea base municipal, los cálculos de reducción son proyecciones |
| **Responsable** | El Ayuntamiento debe proporcionar datos reales del trámite; el proponente proporciona la metodología de simplificación |
| **Fundamento** | LNETB Art. 34; Ley de Gobierno Digital de Nayarit Arts. 2, 5, 6 |
| **Estado** | 🟡 Preparado — metodología lista, datos reales pendientes |
| **Evidencia física** | `demo/constancia-residencia/index.html`, `01_PROBLEMA_PUBLICO/DIAGNOSTICO_DEL_PROBLEMA.md` |

# FICHA TÉCNICA DEL TRÁMITE

## Constancia Municipal de Residencia — Tepic, Nayarit

---

| Atributo | Valor |
|---|---|
| **Nombre oficial** | Constancia Municipal de Residencia |
| **Clave en Catálogo Nacional** | 🔵 POR VERIFICAR — no se ha consultado el Catálogo Nacional de Trámites y Servicios |
| **Sujeto obligado** | H. Ayuntamiento de Tepic, Nayarit |
| **Dependencia responsable** | 🔵 POR VERIFICAR — Secretaría del Ayuntamiento / Oficialía de Padrón y Registro (por confirmar) |
| **Fundamento jurídico municipal** | 🔵 POR VERIFICAR — Bando de Policía y Buen Gobierno de Tepic / Reglamento Interior del Ayuntamiento |
| **Fundamento estatal** | 🟢 Ley Orgánica Municipal del Estado de Nayarit |
| **Fundamento federal** | 🟢 LNETB (DOF 16-jul-2025) — Art. 34, 66, 67, 68, 69 |
| **Objeto** | Acreditar el domicilio de una persona dentro de la jurisdicción del municipio de Tepic |
| **Población objetivo** | ~490,000 residentes del municipio de Tepic |
| **Usos típicos** | Trámites escolares (inscripciones, becas), trámites laborales (contrataciones), trámites bancarios (apertura de cuentas), programas sociales (PROSPERA, pensión adultos mayores), trámites migratorios |
| **Tipo de resolución** | 🔵 POR VERIFICAR — Acto administrativo reglado (debe emitirse si se cumplen requisitos) o discrecional |
| **Plazo de resolución** | 🔵 POR VERIFICAR — Estimado 1-3 días hábiles (requiere confirmación del Ayuntamiento) |
| **Costo** | 🔵 POR VERIFICAR — $0-150 MXN según Ley de Ingresos Municipal de Tepic 2026 |
| **Vigencia típica** | 🔵 POR VERIFICAR — Generalmente 3 meses (requiere confirmación) |
| **Requiere firma de autoridad** | 🟢 Sí — Presidente Municipal o Secretario del Ayuntamiento (por determinar) |
| **Medio de presentación actual** | Presencial |
| **Medio de presentación propuesto** | Digital (web + móvil) |
| **Nivel de digitalización objetivo** | Nivel 5 — Totalmente digital, resolución automatizada con firma de autoridad |

## Actores institucionales en el trámite

| Actor | Función actual | Función propuesta |
|---|---|---|
| Ciudadano | Acude, entrega documentos, recoge | Inicia desde casa, recibe notificación |
| Ventanilla/recepción | Recibe documentos, orienta | Eliminada — portal digital |
| Validador administrativo | Revisa documentos, captura datos | Eliminado — validación automática |
| Funcionario firmante | Firma la constancia | Firma electrónica (requiere designación) |
| Tesorería | Cobra derechos (si aplica) | Pago digital integrado (si aplica) |

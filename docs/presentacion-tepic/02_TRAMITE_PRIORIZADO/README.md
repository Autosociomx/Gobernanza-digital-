# 02 — TRÁMITE PRIORIZADO

## Ficha estándar

| Campo | Respuesta |
|---|---|
| **Problema** | El trámite de Constancia de Residencia requiere visitas presenciales y documentos que el municipio ya posee en otras dependencias |
| **Afectados** | ~490,000 residentes de Tepic; particularmente quienes requieren constancias para trámites escolares, laborales, bancarios y programas sociales |
| **Obligación/Necesidad** | Fundamentar jurídicamente el trámite, identificar los actores institucionales y los requisitos reales |
| **Propuesta** | Documentar el trámite seleccionado con ficha técnica, fundamento, actores y requisitos |
| **Evidencia** | Marco jurídico documentado en `05_MARCO_JURIDICO/`. Trámite identificado en `diagnostico.md` |
| **Brecha** | El fundamento municipal específico (Bando de Policía, Reglamento Interior) no ha sido localizado. Los requisitos reales deben ser proporcionados por el Ayuntamiento |
| **Responsable** | Área jurídica municipal + dependencia responsable del trámite |
| **Fundamento** | Bando de Policía de Tepic, Reglamento Interior del Ayuntamiento, Ley de Ingresos Municipal 2026 |
| **Estado** | 🟡 Preparado — trámite identificado, marco parcial, actores y fundamento municipal por verificar |
| **Evidencia física** | `05_MARCO_JURIDICO/05.01_MATRIZ_NORMA_ARTICULO_EVIDENCIA.md`, `demo/constancia-residencia/index.html` |

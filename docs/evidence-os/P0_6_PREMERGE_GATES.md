# P0.6 Pre-merge Gates

This file records conditions that must be satisfied before PR #59 is eligible to leave draft status.

## Dependency pinning gate

P0.6 code directly imports AJV Draft 2020-12 and `ajv-formats`, and `html_text_v1` is specified against `parse5@5.1.1`.

Before merge, all three MUST be explicit exact direct development dependencies in both `package.json` and the npm lockfile generated by npm itself:

```json
{
  "devDependencies": {
    "ajv": "8.20.0",
    "ajv-formats": "3.0.1",
    "parse5": "5.1.1"
  }
}
```

Required procedure:

```bash
npm install --save-dev --save-exact ajv@8.20.0 ajv-formats@3.0.1 parse5@5.1.1
npm ci
npm run test:provider-portability
```

Do not manually edit only `package.json` and do not manually fabricate lockfile metadata. The package manifest and lockfile must change atomically through npm so CI reproducibility does not depend on transitive hoisting.

Current status: `BLOCKED_PREMERGE` until an executable npm environment or functional GitHub Actions runner can regenerate and verify the lockfile.

## HTML derivation gate

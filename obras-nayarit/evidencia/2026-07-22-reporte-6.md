# Reporte de integración — 22 de julio de 2026 (sexta consulta)

A diferencia de los reportes anteriores, esta entrada no añade obras: documenta la
**integración del módulo Obras Nayarit dentro del portal ciudadano** (la app React
del repositorio, `src/components/CitizenApp.tsx`), para responder la pregunta de
cómo se vería el módulo dentro del portal en vez de como página independiente.

## Cambios

- **`src/components/ObrasPublicasView.tsx`** (nuevo): vista de auditoría de obra
  pública dentro de la app ciudadana, con el mismo lenguaje visual del resto del
  portal (tarjetas `rounded-[1.5rem]`, paleta slate, acentos de marca, tipografía
  Playfair/Inter). Lee directamente `obras-nayarit/datos/obras.json` como fuente
  única de datos — no se duplica información.
- **`src/components/CitizenApp.tsx`**: se agregó el tab `obras_publicas`, su
  callback `handleGoToObras` y el caso correspondiente en el enrutador de vistas.
  El botón "AUDITAR OBRA PÚBLICA" que ya existía en la pantalla de inicio (antes
  apuntaba a un mapa genérico de demostración) ahora navega a la vista real con
  los datos del registro.
- **`tsconfig.json`**: se activó `resolveJsonModule` para poder importar el JSON
  del registro como módulo tipado.

## Verificación realizada

- `npx tsc --noEmit` sin errores.
- Servidor de desarrollo Vite levantado localmente; se montó temporalmente la
  vista de forma aislada (sin tocar el flujo de autenticación de Firebase, que
  no está configurado en este entorno) para capturar pantallas con Chromium vía
  Playwright y confirmar el render de las 27 obras.
- Se probó el filtro por ámbito (clic en "Municipal") y devolvió correctamente
  8 obras, coincidiendo con el conteo esperado del registro.
- El archivo de arranque (`src/main.tsx`) se restauró a su versión original
  después de la prueba visual; no quedó ningún cambio temporal en el repositorio.

## Nota

Este cambio no modifica los datos de `datos/obras.json`; es exclusivamente la
capa de presentación dentro del portal. Los próximos módulos (salud, educación,
presupuesto municipal, agricultura) pueden replicar el mismo patrón: un
`datos/<modulo>.json` con su esquema propio y una vista `Xxx View.tsx` que lo
consume dentro de `CitizenApp.tsx`.
